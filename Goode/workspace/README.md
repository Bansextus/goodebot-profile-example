# Example Robot — editable Goodecode project

Open this folder in VS Code with Goodecode 1.0.2, or import it into Goodebot 5.1.

Edit `src/main.goode.py`. Verify all ports, motor reversals, wheel measurements, IMU port 8, and pneumatic bank A before deployment.

The example provides a Main autonomous routine, Practice in slot 1, Competition in slot 2, tank drive, L1 Intake, and an A-button Clamp toggle. The autonomous routine drives 24 inches, runs Intake for 300 ms, and activates Clamp.

See the repository's root README (“The Big One”) for setup and GitHub instructions. This is example robot code, not the source of the Goodebot application.
